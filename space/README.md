# Ghana AudioDiT

Text-to-speech for 43 Ghanaian languages and Ghanaian English, using
[ghanaopenai/ghana-audiodit](https://huggingface.co/ghanaopenai/ghana-audiodit).

This is a static page; generation runs on an inference server
(`server/` in [GhanaOpenAI/ghana-audiodit](https://github.com/GhanaOpenAI/ghana-audiodit)).
The server address is set in `config.json`.
